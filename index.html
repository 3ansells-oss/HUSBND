Set up HUSBND

One-time setup, done once per phone.

This app needs a free Firebase project to sync chores between your two phones. If this is the very first phone being set up, create the project first (takes about 3 minutes):
  1. Go to console.firebase.google.com and create a project.
  2. Build → Firestore Database → Create database (any region, start in production mode).
  3. Build → Authentication → Get started → Sign-in method → Anonymous → Enable.
  4. Project settings (gear icon) → scroll to "Your apps" → add a Web app → copy the firebaseConfig object it gives you.
  5. Paste that whole snippet below.
Already have the config from setting up the first phone? Just paste the same snippet here too.

Full walkthrough with screenshots-free instructions is in the README that came with this app.

About

HUSBND turns household chores into BJs — a made-up currency. Propose a chore with a BJ value, negotiate the price, get it done, and get it approved to bank the BJs.
